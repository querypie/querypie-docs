# 11.6.0 ~ 11.6.10

### QueryPie 11.6.10 Release

November 03, 2026

**Improvement**

* [Common] Addressed Java runtime security vulnerability (CVE-2026-114820)
    * CVE-2026-114820
        * A compromised root CA certificate included in the Java runtime trust store could undermine certificate validation trust in TLS communications that rely on that root CA
        * Action: Upgrade to Corretto 17.0.21.0.11 or later and remove the affected root CA from the trust store (cacerts)

### <br/>QueryPie 11.6.9 Release

October 29, 2026

**Improvement**

* [Common] Addressed Apache Tomcat and Java runtime security vulnerabilities
    * CVE-2026-101356
        * Requests and responses could be mixed up during HTTP/2 asynchronous processing
        * Action: Upgrade to Tomcat Embed 10.1.61 or later
    * CVE-2026-101296
        * Incorrect passwords could be accepted in non-GSSAPI SASL authentication for JNDIRealm
        * Action: Upgrade to Tomcat Embed 10.1.61 or later
    * CVE-2026-93446
        * TLS 1.3 connections could intermittently fail
        * Action: Upgrade to Tomcat Embed 10.1.61 or later
    * CVE-2026-88041
        * Trailer information from a previous HTTP/2 request could leak into the next request
        * Action: Upgrade to Tomcat Embed 10.1.61 or later
    * CVE-2026-74049
        * Page processing could continue after a JSTL c:redirect instead of stopping
        * Action: Upgrade to Tomcat Embed 10.1.61 or later
    *  CVE-2026-74048
        * The system could keep running in non-FIPS mode when FIPS activation fails
        * Action: Upgrade to Tomcat Embed 10.1.61 or later
    * CVE-2026-91403
        * Forged TLS certificate chains could be trusted due to the eMudhra intermediate CA private key leak
        * Action: Upgrade to Corretto 17.0.21.0.10 or later and apply the Engine bundled JRE measures
