# Dry Run 기능으로 클라우드 동기화 설정 확인하기

### Overview

클라우드 동기화 Dry Run 이란? <br/>클라우드 동기화 수행 프로세스를 테스트하고 검증하는 역할로, 동기화 결과가 무엇인지 미리 확인할 수 있도록 합니다. <br/>기존 연동 정보를 변경하는 경우, 사용자의 입력 실수에 의해 예상치 못한 결과가 발생할 수 있습니다.
이런 문제를 미리 예방하기 위해 사용자는 기존 정보를 변경한 뒤 “Dry Run”을 수행하여 입력한 내용에 대해 미리 테스트해 볼 수 있습니다.<br/>

### Dry Run 수행하기

1. Databases &gt; [Connection Management] &gt; Cloud Provider의 목록에서 특정 클라우드 항목을 선택합니다.
2. 상세페이지에서 변경하고자 하는 설정 항목을 변경한 뒤 우측 상단의 `Dry Run` 버튼을 클릭합니다.

### Credential을 변경한 경우 설정을 저장 하기 전 Dry Run 실행하기

Credential을 변경한 뒤 저장하지 않은 상태에서도, 변경 내용으로 Dry Run을 실행해 인증과 동기화 대상을 미리 확인할 수 있습니다.

기존 Dry Run은 저장된 Cloud Provider 정보를 기준으로 실행되었습니다.
이제는 현재 화면에 입력된 Credential과 Search Filter를 그대로 사용하므로, 저장 전에 변경 내용을 검증할 수 있습니다.

<Callout type="info">
본 기능은 **11.5.9, 11.6.7** 부터 지원됩니다.
</Callout>

#### Dry Run 검증 범위

Dry Run은 다음 항목을 확인합니다.

* 입력한 Credential로 클라우드 플랫폼 인증이 가능한지
* Search Filter 조건에 맞는 리소스가 조회되는지
* 동기화 대상 리소스의 목록과 개수

Dry Run은 실제 동기화를 수행하지 않으므로 Cloud Provider, 리소스, 접근 제어 설정이 변경되지 않습니다.

#### 저장 전 Dry Run 실행하기

1. `Admin > Databases > Connection Management > Cloud Providers` 메뉴로 이동합니다.
2. 대상 Cloud Provider를 클릭하여 상세 화면으로 이동합니다.
3. Credential 또는 Search Filter를 변경합니다.
4. 우측 상단의 `Dry Run` 버튼을 클릭합니다.
5. Credential 방식을 변경했고 일회성 입력이 필요한 경우, `Insert more information to synchronize` 팝업이 표시됩니다.
    * **Cloud Access Key** : AWS Access Key ID를 입력합니다.
    * **Cloud Secret Key** : AWS Secret Access Key를 입력합니다.
    * **Service Account JSON** : GCP Service Account JSON을 입력합니다.
    * **Client Secret ID** / **Client Secret Value** : Azure Client Secret 정보를 입력합니다.
6. `Dry Run` 팝업에서 진행률과 로그를 확인합니다.

<Callout type="important">
`Name`, `Cron Expression`을 제외한 항목이 유효하지 않으면 Dry Run이 실행되지 않습니다.
입력 오류 메시지를 먼저 확인합니다.
삭제된 Cloud Provider에서는 `Dry Run` 버튼이 비활성화됩니다.
</Callout>

#### 일회성 Credential 입력이 필요한 경우

Credential 방식에 따라 Dry Run 실행 시 Secret 값을 추가로 요청하는 경우가 있습니다.

* **일회성 입력 필요** : `Access Key`, `Service Account`, `Client Secret`처럼 Secret 값을 직접 입력하는 방식입니다. `Save Credential for Synchronization` 옵션이 꺼져 있으면 Credential이 저장되지 않으므로, Dry Run 실행 시 Secret 값을 한 번 더 입력하도록 요청합니다.
* **일회성 입력 불필요** : `Cross Account Role`, `Instance Profile`, `Profile Credential`, `Workload Identity`, `Vault (GCP)`처럼 QueryPie 외부에 이미 구성된 인증 정보를 사용하는 방식입니다. 별도 입력 없이 Dry Run이 실행됩니다.

<Callout type="important">
`Save Credential for Synchronization` 옵션을 켜면 Credential이 저장되므로 Dry Run 실행 시 Secret 값을 다시 입력하지 않아도 됩니다.
다만 이 옵션을 켠 상태로 저장해야 하며, 저장 전까지는 일회성 입력을 요청합니다.
</Callout>

#### Dry Run 후 저장 및 동기화하기

1. Dry Run 결과가 정상이면 `Save Changes` 버튼을 클릭하여 Credential과 설정을 저장합니다.
2. `Synchronize` 버튼을 클릭하여 실제 동기화를 실행합니다.
3. 동기화 결과를 확인합니다.

<Callout type="important">
Credential을 변경한 뒤 저장하지 않은 상태에서 `Synchronize`를 클릭하면 `Save credential changes before synchronizing.` 안내가 표시되고 동기화가 실행되지 않습니다.
먼저 Credential을 저장한 뒤 동기화합니다.
</Callout>

<Callout type="info">
Cloud Provider 생성 화면에는 `Dry Run` 버튼이 제공되지 않습니다.
생성 시에는 저장 후 상세 화면에서 Dry Run을 실행합니다.
</Callout>
