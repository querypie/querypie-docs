# Web ClientでKubernetesクラスターに接続する

### Overview

<Callout type="info">
KAC Web Clientは現在 `Beta` として提供されています。
</Callout>

KAC Web Clientを使用すると、別途Agentをインストールせずに、ブラウザーから直接Kubernetesクラスターに接続してリソースを探索し、管理できます。

Kubernetesメニューのクラスター詳細画面でConnectボタンからアクセスするか、Roleと特定のクラスターをすでに選択している場合は、ユーザーページ上部メニューのWeb Client項目から直接移動できます。

### クラスターに接続する

#### Roleを選択する

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/image-20260714-101804.png" alt="QueryPie Web &gt; Kubernetes &gt; Kubernetes &gt; Select a Role" width="760" />
<figcaption>
QueryPie Web &gt; Kubernetes &gt; Kubernetes &gt; Select a Role
</figcaption>
</figure>


* 上部メニューで **Kubernetes** をクリックします。
* **Select a Role** ポップアップダイアログで接続に使用するRoleを選択し、**Select** をクリックします。
    * アクセス可能なクラスター一覧はRoleによって異なります。
    * 付与されたRoleがない場合、左側の一覧は表示されません。WorkflowメニューのAccess Role Requestフォームから適切な権限を申請してください。

#### Web Clientで接続する

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/image-20260714-102425.png" alt="image-20260714-102425.png" width="760" />
</figure>


* 左側パネルで接続するクラスターをクリックします。
* 右側の詳細画面で `Connect` ボタンを押してWeb Clientに接続します。

<Callout type="info">
`Open Agent` ボタンをクリックすると、既存のAgent方式でも接続できます。
Agentのインストールおよび使用方法はAgentマニュアルを参照してください。
</Callout>

### リソース一覧を確認する

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/web-client-resource-list.png" alt="*QueryPie Web &gt; Web Client &gt; Resource List*" width="760" />
<figcaption>
*QueryPie Web &gt; Web Client &gt; Resource List*
</figcaption>
</figure>

左側サイドバーでリソース種別を選択すると、該当するリソース一覧が表示されます。

* **All Namespaces** ドロップダウンで特定のNamespaceを選択し、一覧をフィルターできます。
* **Filter by name** 検索欄に名前の一部を入力してリソースを検索できます。
* `+ Create` ボタンで新しいリソースを作成できます。

探索可能なリソースカテゴリーは次のとおりです。

| カテゴリー           | 含まれるリソース                                                   |
| -------------------- | ------------------------------------------------------------------ |
| **Cluster**          | Namespace, Node, PersistentVolume, ClusterRole, ClusterRoleBinding |
| **Workloads**        | Pod, Deployment, StatefulSet, DaemonSet, ReplicaSet, Job, CronJob  |
| **Config & Storage** | ConfigMap, Secret, PersistentVolumeClaim, StorageClass             |
| **Network**          | Service, Ingress, NetworkPolicy, Endpoints                         |
| **RBAC**             | Role, RoleBinding, ServiceAccount                                  |
| **Custom Resources** | クラスターに定義されたCRDリソース                                  |

### リソース詳細情報を確認する

リソース一覧で項目をクリックすると、右側に詳細パネルが開きます。
詳細パネルは4つのタブで構成されています。

#### Overviewタブ

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/web-client-resource-detail-overview.png" alt="*QueryPie Web &gt; Web Client &gt; Resource Detail &gt; Overview*" width="760" />
<figcaption>
*QueryPie Web &gt; Web Client &gt; Resource Detail &gt; Overview*
</figcaption>
</figure>

リソースのメタデータと状態を確認できます。

* **Metadata**: Name, Namespace, UID, 作成日時, Status, Resource Version
* **Controlled By**: 該当リソースを管理する上位リソース（例：Pod → DaemonSet）- 名前をクリックすると、上位リソースの詳細画面へ移動します。
* **Containers**: Podの場合、コンテナー別のイメージ、Ready状態、Restarts回数を確認できます。
* **Labels / Annotations**: リソースに設定されたラベルとアノテーション

#### YAMLタブ

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/web-client-resource-detail-yaml.png" alt="*QueryPie Web &gt; Web Client &gt; Resource Detail &gt; YAML*" width="760" />
<figcaption>
*QueryPie Web &gt; Web Client &gt; Resource Detail &gt; YAML*
</figcaption>
</figure>

リソースの完全なYAML定義を確認し、直接編集できます。**Edit** ボタンをクリックすると編集モードに切り替わり、変更後に保存するとクラスターへ即時に反映されます。

#### Eventsタブ

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/web-client-resource-detail-events.png" alt="*QueryPie Web &gt; Web Client &gt; Resource Detail &gt; Events*" width="760" />
<figcaption>
*QueryPie Web &gt; Web Client &gt; Resource Detail &gt; Events*
</figcaption>
</figure>

リソースに関連するKubernetesイベントを確認できます。
状態変化、スケジューリング、エラー発生時にイベントが記録されます。
Podが正常に動作している場合、イベントがないことがあります。

#### Relationsタブ

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/web-client-resource-detail-relations.png" alt="*QueryPie Web &gt; Web Client &gt; Resource Detail &gt; Relations*" width="760" />
<figcaption>
*QueryPie Web &gt; Web Client &gt; Resource Detail &gt; Relations*
</figcaption>
</figure>

現在のリソースに関連するリソースの階層構造をツリー形式で可視化します。
親子関係にあるリソースを一目で把握し、項目をクリックして関連リソースの詳細情報へ直接移動できます。

### Podログを確認する

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/web-client-log-viewer.png" alt="*QueryPie Web &gt; Web Client &gt; Log Viewer*" width="760" />
<figcaption>
*QueryPie Web &gt; Web Client &gt; Log Viewer*
</figcaption>
</figure>

1. サイドバーで **Pod** を選択した後、一覧で確認するPodをクリックします。
2. 詳細パネル右上の **Logs** ボタンをクリックします。
3. 下部パネルに該当Podのリアルタイムログがストリーミングされます。
    1. **Search logs** 入力欄にキーワードを入力してログを検索できます。
    2. **Follow** チェックボックスを選択すると、最新ログを自動的に追跡します。

### Pod Shellターミナルに接続する

<figure data-layout="center" data-align="center">
<img src="/user-manual/kubernetes-access-control/web-client/web-client-shell-terminal.png" alt="*QueryPie Web &gt; Web Client &gt; Shell Terminal*" width="760" />
<figcaption>
*QueryPie Web &gt; Web Client &gt; Shell Terminal*
</figcaption>
</figure>

1. サイドバーで **Pod** を選択した後、一覧で接続するPodをクリックします。
2. 詳細パネル右上の **Shell** ボタンをクリックします。
3. 下部パネルにインタラクティブターミナルが開き、Podコンテナーに直接コマンドを実行できます。

<Callout type="info">
LogsとShellは同時に複数のタブで開いて使用できます。
各タブにはPod名が表示され、複数Podのログとターミナルをまとめて比較しながら作業できます。
</Callout>

<Callout type="info">
**Web Clientと既存Agent方式の違い**

Q. Web Clientと既存Agent方式の違いは何ですか？

A. Web ClientはブラウザーだけでKubernetesリソースの探索、ログ確認、Shell接続ができます。
Agent方式はkubectlをはじめとするローカルツールと連携し、より幅広い作業が可能です。
どちらの方式も同じ権限体系（Role, Policy）の下で動作します。
</Callout>
