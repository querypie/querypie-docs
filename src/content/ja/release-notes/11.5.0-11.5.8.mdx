# 11.5.0 ~ 11.5.8

### QueryPie 11.5.8 Release

2026年08月25日

* [共通] External API V3（ベータ）にAuditログ照会およびDAC運用APIを追加

* [DAC] Audit Log ExportのSQL Export Request Workflowで一部リクエストが欠落または重複する問題を修正

* [DAC] DataGripでPostgreSQLテーブルDDL照会時に発生するWITH ORDINALITY構文のパースエラーを修正
* [DAC] Data Policy Exclude Groupから削除したユーザーが引き続きマスキング除外対象として処理される問題を修正
* [DAC] DB ConnectionのAccessible Users一覧で権限更新時点のRenewed Atを確認できるよう改善
* [DAC] Dynamic Proxyの想定可能な接続失敗がError Stack Traceとして繰り返し記録されないよう改善

* [DAC] External APIでLedger未対応DBにPolicyとRuleを登録できないよう検証を強化

* [DAC] MongoDB DB Policy Exception Requestでカンマを含むカラムパスが正常に処理されない問題を修正
* [DAC] MySQL Ledger Policy適用時にALTER構文がSQL Request対象として誤処理される問題を修正
* [DAC] MySQL接続失敗時に内部パースエラーではなくTarget DBの実際のエラーが表示されるよう改善

* [DAC] Query Auditフィルター照会時に同一履歴が重複表示される問題を修正
* [DAC] Redshift Datashare Shared Databaseでクエリ実行時に発生するエラーを修正
* [DAC] Redshift ConnectionにImport Batch Size設定を追加し、CSV・Excel Import性能を改善
* [DAC] Trino Proxyで後続リクエストが新しいTCP接続に送信されてもクエリが正常に処理されるよう改善
* [DAC] WHERE条件のない変更・削除のブロック対象をWeb SQL EditorのMongoDB・DocumentDB・DynamoDBとProxyのMongoDB・DocumentDBへ拡大

* [DAC] Workflow Assigneeを複数選択する際にドロップダウンが閉じないよう改善
* [SAC] Azure Cloud Provider APIレスポンス遅延時に同期JobがRunning状態のまま残る問題を修正
* [KAC] GCP Cloud Providerで同期したClusterにAWSアイコンが表示される問題を修正
