# 11.5.0 ~ 11.5.12

### QueryPie 11.5.12 Release

2026年11月03日

**Improvement**

* [共通] Java ランタイムのセキュリティ脆弱性(CVE-2026-114820)に対処
    * CVE-2026-114820
        * Java ランタイムのトラストストアに含まれる侵害されたルート認証局(CA)証明書により、そのルート CA を信頼の基盤とする TLS 通信で証明書検証の信頼が損なわれる可能性がある問題
        * 対応: Corretto 17.0.21.0.11 以上へアップグレードし、トラストストア(cacerts)から該当するルート CA を削除

### <br/>QueryPie 11.5.11 Release

2026年10月29日

**Improvement**

* [共通] Apache Tomcat および Java ランタイムのセキュリティ脆弱性に対処
    * CVE-2026-101356
        * HTTP/2 の非同期処理でリクエストとレスポンスが混在する可能性がある問題
        * 対応: Tomcat Embed 10.1.61 以上へアップグレード
    * CVE-2026-101296
        * JNDIRealm の non-GSSAPI SASL 認証で誤ったパスワードが許可される可能性がある問題
        * 対応: Tomcat Embed 10.1.61 以上へアップグレード
    * CVE-2026-93446
        * TLS 1.3 接続が断続的に失敗する可能性がある問題
        * 対応: Tomcat Embed 10.1.61 以上へアップグレード
    * CVE-2026-88041
        * 以前の HTTP/2 リクエストの trailer 情報が次のリクエストに混在して露出する可能性がある問題
        * 対応: Tomcat Embed 10.1.61 以上へアップグレード
    * CVE-2026-74049
        * JSTL c:redirect 後にページ処理が中断されず継続して実行される可能性がある問題
        * 対応: Tomcat Embed 10.1.61 以上へアップグレード
    *  CVE-2026-74048
        * FIPS の有効化に失敗した場合に non-FIPS モードで動作し続ける可能性がある問題
        * 対応: Tomcat Embed 10.1.61 以上へアップグレード
    * CVE-2026-91403
        * eMudhra 中間 CA の秘密鍵流出により偽造された TLS 証明書チェーンが信頼される可能性がある問題
        * 対応: Corretto 17.0.21.0.10 以上へアップグレードし、Engine bundled JRE の対応を適用
